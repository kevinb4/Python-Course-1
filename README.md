# Python Course Work

A collection of Python scripts completed as part of an introductory programming course, covering core language fundamentals through small, standalone assignments.

## Topics Covered

- Variables and data types
- User input handling
- Conditional statements
- While loops
- Lists
- Dictionaries
- Functions
- Classes and object-oriented programming (inheritance, input validation)

Notable example: `classes_assignment.py`: A college records system demonstrating OOP concepts - a base Individual class with Student and Instructor subclasses (inheritance, method overriding), plus a Validator class that checks user input for correct format (ID length, valid characters for names/emails) before records are added to a running list.

Each file is self-contained and runnable independently to demonstrate a specific concept.
